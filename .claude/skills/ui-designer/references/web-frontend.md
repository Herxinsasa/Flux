# Web 界面契约参考

仅用于解释 Web UI 稿和补齐界面约束，不输出前端技术实现设计。

| 维度 | 需要确认 |
|------|----------|
| 页面载体 | 页面、弹窗、抽屉、表单、列表或局部区域 |
| 入口 | 导航、按钮、菜单、链接或自动展示条件 |
| 字段 | 标签、单位、格式、默认展示、必填和只读状态 |
| 交互 | 输入、选择、提交、取消、跳转、联动和反馈 |
| 状态 | 本需求涉及的加载、空、错误、禁用、成功状态 |
| 响应式 | 最小宽度、换行、滚动、溢出和移动端要求 |
| 视觉 | 复用的组件样式、间距、颜色、字号和图标 |
| 验收 | 与稿件对比的页面、状态和操作结果 |

边界：不描述目标源码、组件拆分、状态管理、接口映射、缓存和兼容实现。
