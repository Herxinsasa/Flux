- [ ] **A-02 评审人追问**：在同一批注中切换“评审人”并回复；两种身份标签清晰可区分，顺序正确。

- [ ] **A-04 导出线程**：分别导出 Markdown 和 HTML；根批注与所有回复均出现，评审人/修改人标识正确。
