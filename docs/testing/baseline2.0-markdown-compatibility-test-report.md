## 已覆盖风险

- 单波浪线保留普通文本，双波浪线才解析为删除线。
- CommonMark 软换行、硬换行和列表内引用语义保持一致。
- `[TOC]` 仅在根级独立段落生效，编辑/预览可展示并跳转，嵌套内容不误判。
- Milkdown 创建与销毁串行执行，快速切换文件不会由旧实例清理新实例上下文。
- 编辑器创建失败时回退到源码界面，避免正文只能显示空白。
- 75%-250% 缩放保持内容居中；图片和 Mermaid 只应用一次内容倍率。
- 缩小视图不产生布局型横向滚动，放大媒体由外层滚动容器承载。

## 人工验收边界

JSDOM 和单元测试不能可靠衡量 Electron 中的输入延迟、滚动帧率、字体渲染与视觉居中。以下项目仍需使用 `docs/testing/baseline2.0-markdown-compatibility-checklist.md` 实测：

- 10KB、500KB、1MB 文档的输入和滚动流畅度。
- 连续切换真实工作区文件 20 次的视觉稳定性。
- 75%、94%、100%、150%、250% 下的居中、滚动和媒体清晰度。
- 中文标题、重复标题、图片、Mermaid、表格和任务列表的真实主题效果。
