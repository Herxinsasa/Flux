## 第二轮复审

发现供应商切换后旧请求的 `finally` 不再清理转圈状态，以及锁文件按固定 30 秒接管可能误伤仍存活的慢写进程。

- 切换供应商时立即复位刷新状态，旧请求只结束自身、不再修改新表单。
- 锁文件记录持锁 PID 与随机 token；仅在持锁进程不存在时接管，释放前必须匹配 token。

## 结论

最终双人复审确认所有已报 P1 均关闭，未发现新增 P0/P1。等待人工 UI 验收，打包未执行。
