# baseline2.1 编辑交互优化需求规格

> 状态：已确认
> 需求来源：2026-08-15 用户迭代指令
> 设计宗旨：轻量、高效、流畅的 Markdown 文本阅读与编辑

## 需求项

| ID | 名称 | 级别 | 目标 | 验收标准 | UI |
|----|------|------|------|----------|----|
| REQ-001 | 精简编辑模式 | 小 | 仅保留“编辑 / 源码”，移除分栏入口和实现噪声 | 工具栏无分栏；“即时编辑”改为“编辑”；旧分栏状态可安全回落 | 是 |
| REQ-002 | 左侧大纲 | 小 | 大纲靠近文件树侧，符合从左到右的导航习惯 | 打开大纲后显示在编辑区左侧；切换文件自动关闭；标题跳转可用 | 是 |
| REQ-003 | 统一 Markdown 右键菜单 | 大 | 编辑与源码使用相同的信息架构 | 两种模式均有引用、批注、样式、段落、插入；依赖文本的操作在无选择时禁用；AI 未配置时引用禁用 | 是 |
| REQ-004 | 整体可读性提升 | 小 | 全局常用字号与图标放大一级 | 主工具栏、菜单、侧栏和常用按钮可读性提升，布局无溢出 | 是 |
| REQ-005 | Markdown 内容缩放 | 中 | 编辑与源码内容均可独立放大、缩小和复位 | Ctrl+=、Ctrl+-、Ctrl+0 可用；工具栏可见当前比例；不缩放应用壳 | 是 |
| REQ-006 | 表格结构编辑 | 大 | 在编辑模式提供行列操作和单元格对齐 | 表格内可选行/列、前后增加、删除并设置左/中/右对齐；非表格区域不显示表格控件 | 是 |

## 统一交互规则

- “引用”表示把选中文本送入 AI 对话输入上下文，不执行模型请求。
- AI 配置有效条件：至少存在一个带非空 API Key、Base URL 和模型的 Provider。
- 无文本选择时禁用：引用、批注、粗体、斜体、行内代码、引用块和列表转换。
- 标题作用于当前段落；插入类命令在光标位置工作，无需选择文本。
- 插入菜单首发包含：链接、图片、表格、代码块、分割线。
- 表格结构操作仅属于“编辑”模式；源码模式仅提供 Markdown 表格插入。

## 非本次范围

- Office/PDF 阅读编辑、多人实时协作、表格公式、复杂跨行跨列合并。
- 新增 AI Provider 协议或修改批注侧车格式。
- 打包与发布。

## 聚合风险

编辑器由 Milkdown 与 CodeMirror 两套内核组成，命令语义必须统一但实现适配必须分离；不能用 Markdown 字符串猜测替代表格结构命令。
