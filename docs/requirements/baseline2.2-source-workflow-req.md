# baseline2.2 源码与文档安全修复需求

## 目标

在不扩展 Office 或图片生成能力的前提下，继续强化 Flux 作为轻量、流畅的 Markdown/TXT/LOG 阅读编辑器的核心体验。本轮优先解决长文本源码编辑、双编辑面一致性、批注可达性，以及未保存内容安全。

## 范围

### REQ-201 源码编辑交互

- Markdown 源码模式移除选中文本后自动出现的 AI 浮动工具条。
- 源码模式仅保留与编辑模式一致的右键菜单。
- CodeMirror 继续负责源码编辑并保持视口虚拟化；输入期间不得因全文受控回写、选区浮层定位或同步全文派生计算而触发不必要的 React 重渲染。
- 日常长文本应可连续输入、选择、滚动和保存；完整文本加载上限提高到 16 MB，超过上限继续使用只读采样或日志索引。超过富文本安全预算的 Markdown 默认使用源码模式。

### REQ-202 双模式批注

- 源码模式选中文本后可通过右键“批注”创建侧车批注。
- 编辑模式选中渲染后的文字后同样可创建批注，包括粗体、斜体、链接文字等含 Markdown 标记的内容。
- 批注不得写入原 Markdown 正文。

### REQ-203 编辑命令统一

- 顶部导航栏使用与右键菜单相同的“样式 / 段落 / 插入”命令模型。
- 同一命令在当前可见的编辑模式或源码模式执行，不得隐式切换界面。
- 需要选区的命令在无选区时禁用；插入和标题命令允许在光标位置执行。

### REQ-204 双模式大纲

- 编辑模式与源码模式互斥显示。
- 源码模式点击大纲按源码行跳转。
- 编辑模式点击大纲跳转到当前富文本文档中的对应标题，不切换到源码。
- 重名标题按文档顺序区分。

### REQ-205 界面剪枝

- 所有返回按钮去掉左箭头，仅显示“返回”。
- 设置页删除“阅读与编辑”可见设置区；编辑器内容缩放仍保留。
- 当前版本不存在 AI 绘画设置，本轮不新增设置页或入口。

### REQ-206 恢复与未保存保护

- 恢复内容预览使用 Markdown 渲染模式，不展示源码文本块。
- 当前文档有未保存修改时，切换文件或关闭软件必须出现“保存 / 不保存 / 取消”提示。
- 保存成功后继续原操作；保存失败或取消时停留在当前文档；不保存时仅放弃本次未保存草稿。
- 工作区文件、标签、最近文件、Markdown 链接、系统文件关联和 Ctrl+Tab 统一走文件切换保护。

## 非目标

- 不增加 Word、PDF 或 Office 预览。
- 不增加 AI 绘画能力或对应设置。
- 不取消超大文件采样、日志索引与只读保护。
- 不在人工验证前打包发行产物。

## 验收标准

- 右键菜单和顶部菜单的命令集合、禁用规则及执行结果一致。
- Markdown 源码选区不再弹出 AI 浮层。
- 编辑模式可对含行内格式的选区创建批注。
- 两种模式的大纲点击均在当前界面定位。
- 1-2 MB 范围内长 Markdown 源码连续输入和滚动无明显阻塞，输入不会驱动整个 Markdown 外壳按键级重渲染。
- 所有文件切换入口和窗口关闭均覆盖未保存三选一流程。
- 恢复预览按 Markdown 样式展示。
