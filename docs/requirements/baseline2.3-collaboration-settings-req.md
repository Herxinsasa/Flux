# baseline2.3 协作与设置优化需求

## 目标

在不增加产品复杂度的前提下，强化 Flux 的团队评审、表格编辑、工作区布局与 AI 配置体验。

## 范围

1. 批注支持线程回复，并明确区分评审人与修改人。
2. 编辑模式表格左上角统一提供行列调整、左对齐、居中、右对齐四个入口。
3. 工作区默认显示，支持从顶栏一键隐藏和恢复。
4. 设置页统一术语和层级；删除主题配置；AI 会话数据归入默认折叠的高级设置；支持从供应商接口刷新模型列表。

## 非目标

- 不引入 Office、PDF 或图片生成配置。
- 不改变 Markdown 文件内容来保存批注。
- 不打包发布，先完成开发环境和人工验收。

## 验收摘要

- 旧 `.review.json` 能继续读取，新回复随侧车原子保存。
- 表格选中后只出现统一的四按钮工具条。
- 工作区隐藏状态持久化，首次使用默认显示。
- 模型刷新失败有明确反馈，不覆盖当前模型；成功后可直接选择最新列表。
- 会话数据设置仍需显式保存，避免误改持久化策略。
