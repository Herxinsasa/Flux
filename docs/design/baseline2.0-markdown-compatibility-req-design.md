# baseline2.0 Markdown 兼容性技术设计

## 解析基线

- 预览：markdown-it 使用 CommonMark 默认换行语义，叠加表格、任务列表、脚注和安全本地资源协议。
- 编辑：Milkdown GFM 配置 `singleTilde: false`，并用仅接受双波浪线的输入规则替换默认规则。
- 删除会改变源语义的列表/引用预处理，源码含义由标准解析器决定。

## TOC

- 源码契约：仅独占一行、忽略大小写的 `[TOC]` 被识别为目录。
- 预览：markdown-it core rule 将占位段落替换为只读目录，链接复用 `md-line-N`。
- 编辑：remark 转换插件将占位段落映射为原子 `toc` 节点；NodeView 根据当前 ProseMirror 文档中的 H1-H6 生成目录。
- 编辑事务后刷新 TOC；点击条目设置标题附近选区并滚动到可视区域。
- 序列化始终写回 `[TOC]`，不把生成的链接列表写入源文件。

## 生命周期与失败回退

- 同一组件实例维护编辑器生命周期 Promise 链。
- 文件切换时先保存选区和滚动位置，等待旧实例销毁后再创建新实例。
- 失败时记录错误并切到源码界面，正文仍由 editorStore 保留。

## 缩放

- 文本、图片和 Mermaid 使用同一个内容缩放值。
- 编辑根节点使用补偿宽度和对称偏移保持中心不动。
- 图片上限随放大比例补偿，避免 `max-width: 100%` 抵消缩放。
- 缩小时不产生无意义横向滚动，放大时允许查看超出内容区的大图。

## 性能

- 保留 1,500,000 字符富文本上限和大文件源码模式。
- 文件切换不并发创建 Milkdown 实例。
- TOC 扫描仅遍历 ProseMirror 文档，刷新与编辑事务合并。
- 自动化测试覆盖语法、往返、连续切换和缩放计算；人工清单覆盖真实 Electron 滚动与视觉体验。
