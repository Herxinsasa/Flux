## P2：表格单元格垂直对齐

- 状态：待评估
- 来源：编辑器表格交互优化
- 目标：在现有列水平对齐基础上，为选中单元格或行提供顶部、居中、底部的垂直对齐。
- 说明：当前仅支持列的水平对齐；该项涉及 Milkdown/ProseMirror 表格属性、编辑工具条和 Markdown 导出兼容性，需要独立评估后排期。

## P3：多窗口

- 状态：待评估
- 来源：编辑器工作流讨论
- 目标：支持同时打开多个 Flux 窗口，便于并行阅读、编辑和对照文档。
- 说明：需要明确窗口与工作区的关系、会话隔离、未保存状态提示、文件监听及单实例策略，暂不纳入当前迭代。
