# baseline2.1 编辑交互界面契约

> 状态：已确认
> 来源：用户文字说明与现有 Flux UI
> 平台：Windows Electron

## 编辑工具栏

- 左侧顺序：文件名、编辑、源码、大纲。
- 右侧为缩小、当前比例、放大、复位；使用 Lucide 图标和 tooltip。
- “编辑”为默认模式；不出现“分栏”。
- 大纲展开在正文左侧，宽度保持稳定，窄窗口允许正文收缩但不可覆盖。

## 右键菜单

- 顶层顺序：引用、批注、分隔线、样式、段落、插入。
- 子菜单向右展开；靠近屏幕右缘时向左展开。
- 禁用项保留位置并降低透明度，不显示冗余原因文字；tooltip/原生 title 可说明 AI 未配置。
- 菜单字号不小于全局小字号，行高适合鼠标快速点击。

## 表格控件

- 光标进入表格后，在表格左上角显示紧凑控制柄。
- 控制柄打开表格菜单：选择行/列、前后增加、删除、左/中/右对齐。
- 使用图标与 tooltip；操作后焦点回到表格。
- 非表格区域不显示，避免常驻提示。

## 状态验收

| 状态 | 期望 |
|------|------|
| 无选择 | 依赖选区的菜单项禁用，插入与段落项可用 |
| AI 未配置 | 引用禁用，其余本地编辑能力不受影响 |
| 只读 | 所有修改类命令禁用 |
| 表格内 | 表格控制柄出现且不遮挡单元格文字 |
| 100%-200% 缩放 | 正文可滚动，工具栏和侧栏不随内容缩放 |
