# baseline2.0 团队 AI Markdown 编辑器界面设计

> 状态：已确认（代理自审）
> 来源：现有 Flux 界面、需求规格与影响面分析
> 平台：Electron / Windows 桌面
> 关联需求：REQ-001、002、004-009、011-013、016-018

## 1. 设计目标

默认界面只承担“找到文本、阅读、编辑、保存”四件事。AI、批注和恢复能力按需出现，不用常驻说明占据阅读空间。延续现有深浅主题、标题栏和三栏结构，只调整默认状态与必要交互，不重做品牌系统。

- 默认是文件树加编辑器，AI 面板隐藏但保持会话生命周期。
- 采用图标按钮表达折叠、批注、AI、打开、保存等熟悉动作，悬停显示名称。
- 不使用营销式首页、嵌套卡片或大面积装饰；空状态仍是可立即工作的文件入口。
- 成功操作尽量静默；仅失败、冲突、数据恢复和不可逆操作显示明确提示。
- 面板、工具栏和标签尺寸稳定，动态内容不推动主编辑区跳动。

## 3. 主工作区

### 3.1 默认布局

| 契约项 | 内容 |
|---|---|
| 布局 | 左侧文件树 240px；中央编辑区占剩余宽度；右侧 AI 面板默认折叠为 0 |
| 标题栏 | 左侧菜单和工作区名；右侧依次为批注、AI、主题、设置等图标入口 |
| 最小宽度 | 960px；不足时文件树可折叠，编辑区最小 520px |
| 极简模式 | 一次动作同时折叠文件树、批注栏和 AI 面板；再次执行恢复上次宽度与可见状态 |
| AI 隐藏 | 隐藏不取消进行中的生成，不清空消息和上下文；流式生成时 AI 图标有低调进行态 |
| 持久化 | 恢复上次面板可见性、宽度和极简模式前状态；新用户仍以 AI 隐藏开始 |

快捷入口：`Ctrl+Shift+L` 切换极简模式，`Ctrl+/` 呼出或隐藏 AI。快捷键不在界面常驻解释，仅在按钮 tooltip 与菜单中出现。

### 3.2 文件标签与导航

- 顶部文件标签使用固定高度，显示文件名、脏状态圆点和关闭图标。
- 标签宽度有上下限，溢出后水平滚动，不挤压编辑工具栏。
- `Ctrl+Tab` 按最近使用顺序切换，`Ctrl+Shift+Tab` 反向；切换时短暂显示紧凑文件切换器。
- 每个打开文件保留正文草稿、模式、光标和滚动位置；切换不弹出保存确认。
- 关闭脏文件才显示保存、放弃、取消三项确认。

## 4. 空状态与最近文件

中央空状态不是介绍页，首屏结构固定为：

1. 顶部紧凑操作行：打开文件、打开文件夹。
2. 最近项目列表：最多 10 项，显示名称、类型图标、父路径、上次打开时间；单击打开，右键可从列表移除。
3. 首次使用时，在列表下方显示三条可关闭提示：打开文本、开始编辑、按需使用 AI。完成任一对应动作后自动弱化，全部完成或主动关闭后不再出现。

状态：

- 无最近项：只显示两个打开动作和拖放区域。
- 路径失效：该行弱化并显示移除图标，不自动弹错。
- 打开失败：行内显示简短原因并保留重试。
- 加载最近项：使用固定高度骨架，避免空状态跳动。

## 5. 编辑体验

### 5.1 Markdown

- 模式使用三段式分段控件：编辑、阅读、分栏。首版不再把只读预览称为 WYSIWYG。
- 编辑模式接入所见即所得编辑器仅在无损往返验证通过后启用；遇到不支持语法时保留源码并提示切换源码编辑。
- 阅读视图采用清晰的 H1-H6 层级、适中行宽、代码块与正文有明暗差、表格列对齐并允许横向滚动。
- 工具栏保持单行；窗口不足时低频动作进入更多菜单，不换行挤压正文。

### 5.2 TXT 与 LOG

- TXT 使用纯文本编辑器，不显示 Markdown 工具栏。
- LOG 默认只读；大文件进入虚拟列表，顶部仅保留搜索、级别筛选、自动跟随和重新索引。
- 索引中显示细线进度和取消图标，正文区域仍可操作已有内容。
- 二进制或不支持格式显示简洁拒绝页，只提供“用系统应用打开”。

### 5.3 字体设置

设置页新增“阅读与编辑”：界面字体、编辑字体、等宽字体、正文 12-24px、代码 11-22px。下方提供短文本实时预览。字体不存在时回退系统默认，不弹阻塞提示。

## 6. 批注模式

### 6.1 添加与展示

- 选中文本后右键菜单增加“添加批注”；已有选区浮动条的更多菜单也提供同一入口。
- 新批注使用靠近选区的紧凑输入浮层，只包含文本框、保存、取消；空内容不能保存。
- 批注高亮使用琥珀色系，AI 建议使用蓝绿色系；暗色主题保持相同语义但提高对比度。
- 重叠批注使用同一高亮，不叠加颜色；点击后在侧栏展开对应多条批注。
- 锚点失效时不再高亮正文，侧栏显示“位置已失效”，可重新选择文本绑定或删除。

### 6.2 批注侧栏

右侧批注栏与 AI 面板互斥占用主侧栏位置，标题栏图标切换。侧栏宽度默认 320px，可调 280-520px。

内容顺序：文档批注数、未解决/全部筛选、按正文位置排序的批注列表。每项显示引用片段、批注正文、来源（用户/AI）、状态和紧凑操作菜单。点击项滚动正文，点击高亮滚动侧栏。

无批注时只显示一行空状态，不展示教学说明。

### 6.3 导出

侧栏更多菜单进入“导出批注”，弹窗仅包含：

- 格式：Markdown / HTML。
- 呈现：脚注式 / 文末清单。
- 范围：全部 / 未解决。
- 导出按钮与取消按钮。

导出成功后显示文件位置与“在文件夹中显示”；失败保留用户选择并显示原因。

## 7. AI 交互

### 7.1 选区工具条

选中文本后出现固定高度浮动条：总结、翻译、改写、更多。更多菜单包含解释、扩展、缩写、修正语法、正式、口语化、检查错别字、添加批注。无文本选择时不出现。

- 总结/解释/翻译等只读结果进入紧凑结果浮层，可复制或插入到光标后。
- 改写类显示原文与建议文本，可接受、拒绝；接受前检查正文版本，冲突时不覆盖。
- 请求中只显示停止图标和短状态，不打开完整聊天面板。
- 失败显示一行原因与重试，不输出技术堆栈。

### 7.2 AI 文档评审

从编辑器更多菜单选择“AI 审阅此文”。评审结果先进入批注侧栏的“待确认”筛选，每条可接受为 AI 批注、忽略或全部接受；未确认内容不写侧车文件。取消和失败不产生批注。

### 7.3 对话与 `/compact`

- AI 面板按需呼出；顶部只显示会话标题、上下文状态图标、收起和新会话。
- 输入 `/` 出现命令菜单；`/compact` 在本地拦截，可附加一句关注点。
- 压缩中输入区保持可编辑但发送禁用；成功仅在消息流插入一条“上下文已压缩”；失败保持旧上下文并显示重试。
- 恢复旧会话时只显示一次轻量恢复标识，不展示存储路径、JSONL 或配额等实现信息。

## 8. 备份恢复

- 发现可恢复快照时，在编辑区顶部显示非模态恢复条：文件名、快照时间、预览、忽略。
- 进入恢复抽屉后按时间倒序列出快照；选择后只读预览差异，可“另存为”或“丢弃快照”。
- 不提供一键覆盖原文件按钮。
- 无可恢复内容时不显示入口；自动快照成功不提示，失败连续发生时才显示一次警告。

## 9. 视觉与适配约束

- 卡片圆角不超过 8px；页面分区不使用浮动卡片包裹。
- 正文阅读宽度 720-860px，源码编辑占满可用宽度。
- 颜色至少包含中性背景、蓝色动作、琥珀批注、蓝绿 AI 建议、红色错误，避免单色主题。
- 标题、代码、表格、批注高亮在深浅主题下均满足清晰对比。
- 所有图标按钮至少 32x32px，未知图标必须有 tooltip；文本不得在按钮和标签中溢出。

## 10. UI 验收

- 1440x900、1280x720、960x640 三种窗口下无重叠、无横向页面滚动。
- 默认首屏无 AI 面板；隐藏/显示不取消流、不清空会话。
- 最近项、引导、批注、AI 结果、恢复条均覆盖空、加载、成功、失败状态。
- 键盘可完成文件切换、面板切换、保存、接受/拒绝 AI 建议。
- Markdown 阅读、源码、分栏切换不丢正文；长表格和代码块不撑破布局。
- 通过桌面截图核对深浅主题、紧凑窗口和高 DPI 缩放。

非本次范围：移动端、Office/PDF 预览编辑、实时多人协作、云端批注同步、完整设计系统重构。
